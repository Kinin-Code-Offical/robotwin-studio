# Dependencies

What RobotWin Studio ships and builds on, with each licence. Generated by `tools/scripts/dependency_inventory.py` from what the projects resolve (`dotnet list package --include-transitive`) and the packages' own `.nuspec`; CI fails when it is out of date or a licence is not on the allowed list (0BSD, Apache-2.0, BSD-2-Clause, BSD-3-Clause, ISC, MIT, MS-PL, Unlicense, Zlib). The licence texts of the bundled components are in `THIRD_PARTY_NOTICES.md`.
